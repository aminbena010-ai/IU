# IU

Motor de renderizado ligero, estable y seguro, escrito en Rust.

- **Producto que lo usa**: Foxium (navegador).
- **Filosofía**: Rust para la lógica propia, librerías auditadas para las piezas gigantes (html5ever, cssparser, rustls, tiny-skia, rquickjs).
- **Arquitectura**: multiproceso Browser + Renderer con sandbox e IPC validado.
- **Licencia**: Apache 2.0.
